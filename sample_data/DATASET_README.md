# Northstar Demo University - Synthetic Dataset

This folder contains four synthetic PDF documents created for the UniGuide-RAG classroom prototype. Northstar Demo University is fictional. No real university, college, student, office or institutional regulation is represented. All attendance values, dates, examination rules, service hours and contacts are invented. The contact address uses the reserved `.example` domain.

Files:

- `northstar_student_handbook_demo.pdf`
- `northstar_assessment_exam_guide_demo.pdf`
- `northstar_academic_calendar_demo.pdf`
- `northstar_library_it_services_demo.pdf`

Each PDF carries a visible warning that it is fictional demo material. These sources can be loaded in the Streamlit app with **Load built-in demo documents**.
